# Clarifications

## Questions and Decisions

Q1. Should the application be dynamic?
Decision: No. It will be a static JSP page only.

Q2. Should the project use Spring Boot?
Decision: No. Use a simple Maven WAR project for beginner-friendly learning.

Q3. Should Jenkins deploy the WAR file?
Decision: No. For this workshop, Jenkins will build and archive the WAR artifact only.

Q4. Should CSS be in a separate file?
Decision: No. Keep basic CSS inside index.jsp for simplicity.

Q5. What should the page content focus on?
Decision: Focus on practical benefits of SDD: clarity, alignment, traceability, better testing, less rework, and CI/CD readiness.

Q6. Which server will run the app?
Decision: Learners may deploy the WAR to Tomcat, or the facilitator may demonstrate the build only if Tomcat is unavailable.
